# Analisis Perbandingan Platform

## 1. Tabel Perbandingan

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa pemrograman | HTML, CSS, JavaScript | C#, Java, Python, C++ | Kotlin, Java, Swift, Dart |
| Arsitektur | Client-server, berjalan melalui browser | Aplikasi berjalan di sistem operasi komputer | Aplikasi berjalan di Android atau iOS |
| Distribusi | Melalui URL dan server web | Installer atau toko aplikasi desktop | Google Play Store atau Apple App Store |
| Kelebihan | Mudah diakses, lintas perangkat, pembaruan terpusat | Dapat memanfaatkan sumber daya komputer dan bekerja offline | Portabel, dapat memakai kamera, GPS, dan notifikasi |
| Keterbatasan | Bergantung pada browser dan sering memerlukan internet | Perlu penyesuaian sistem operasi dan proses instalasi | Perlu memperhatikan ukuran layar, baterai, dan perbedaan perangkat |
| Contoh | Google Docs, Wikipedia | Microsoft Word, VLC Media Player | WhatsApp, Google Maps |

## 2. Kesimpulan

Setiap platform memiliki kegunaan yang berbeda. Platform web cocok untuk layanan yang mudah diakses melalui browser. Platform desktop sesuai untuk aplikasi komputer yang membutuhkan kemampuan sistem secara lebih luas. Platform mobile cocok untuk penggunaan sehari-hari karena dapat memanfaatkan fitur perangkat seperti kamera dan GPS.

## 3. Refleksi Pembelajaran

Platform yang paling menarik bagi saya untuk dipelajari adalah platform mobile. Selain itu, saya tertarik mempelajari cara membuat aplikasi Android menggunakan Android Studio.

Namun, setelah mencoba kembali dan mengikuti langkah-langkah yang benar, saya berhasil membuka folder repository menggunakan Visual Studio Code.

Untuk mengatasi tantangan tersebut, saya berencana mempelajari perintah dasar Git secara bertahap dan lebih sering berlatih menggunakan CMD. Saya juga akan memanfaatkan dokumentasi resmi dan materi pembelajaran yang tersedia di internet. Selain itu, saya akan membiasakan diri membuat proyek sederhana agar kemampuan pemrograman saya meningkat. Dengan latihan yang konsisten, saya berharap dapat memahami proses pengembangan aplikasi pada berbagai platform dengan lebih baik.
